# 三条「收纳前后」短视频分镜

## 视频1｜玄关

| 秒数 | 画面 | 口播/字幕 |
|---|---|---|
| 0—3 | 鞋堆挡门，门只能开一半 | “玄关越收越乱？你少做了一步。” |
| 3—12 | 全部清空，按常穿/换季分 | 技巧1：先减量 |
| 12—26 | 竖向鞋架上墙 | 技巧2：用墙面 |
| 26—42 | 托盘收钥匙、口罩 | 技巧3：给小物固定位置 |
| 42—54 | 同机位前后对比 | 字幕：地面空出来了 |
| 54—60 | 人物开门 | “你家最难收拾的地方是哪？” |

BGM：轻快、有清晰三拍转场；道具：鞋架、托盘、标签、垃圾袋。

## 视频2｜衣柜

钩子：“衣柜不是小，是同一件衣服占了三个位置。”三技巧：按使用频率分区、同方向薄衣架、换季衣物装袋并标日期。结尾展示一周穿搭区。避坑：不要为了画面整齐把常用衣服塞到最上层。

## 视频3｜厨房台面

钩子：“台面只留每天都用的，做饭能快十分钟。”三技巧：调料集中托盘、锅盖竖放、清洁用品离开操作区。前后镜头必须固定焦距和光线，不用夸张广角欺骗空间。

三条视频统一保留同机位、同光线的前后对比，结尾评论问题保持一致，方便比较完播、收藏和评论率。拍摄清单：每条先录完整“乱态”；收纳动作拍近景；字幕每屏不超14字；产品只在解决问题时出现；涉及承重、耐热须按真实说明书。建议周一玄关、周三衣柜、周六厨房分批发。
